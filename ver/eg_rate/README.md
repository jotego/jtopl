Run `./run.sh` with Icarus Verilog, or `simunit.sh` in a JTCORES checkout. The test checks release selection, all
register rates and key-scale offsets, counter-driven decay totals for rates 12–63, the
update gate and attenuation saturation. Fast-rate totals use the OPL increment
pattern and the two internal units per chip attenuation step.
